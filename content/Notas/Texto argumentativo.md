# El texto argumentativo

## Objetivos
- Convencerlo de una postura o teoría.
	- Requiere determinar razones.
## Características
 - El texto debe ser adecuado al contexto.
 - Tener coherencia textual.
	 - La información es adecuada, ordenada, estructurada.
- Cohesión.
	- Buena conexión entre las partes.
		- Evitar repeticiones.
		- Usar sinónimos y antónimos.
		- Agregar conectores.
## Partes
1. Introducción
	- Presentar asunto tratado y posición.
2. **[[Argumentación]]**
	- Corazón del texto.
	- Cada argumento es un párrafo.
3. Tésis
	- Idea principal que se defiende.
4. Conclusión.
