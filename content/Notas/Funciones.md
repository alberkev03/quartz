# Funciones
- Relación entre dos variables independientes en un eje cartesiano (“x” e “y”).
	- Eje de las abscisas es la letra x y es donde se representa las variables independientes; eje de ordenada es la letra y y representa las variables dependientes.
		- A cada punto le corresponde solo un dependiente y un independiente.
- Elementos de una función:
	- Dominio: Conjunto de valores independientes (eje X).
	- Imagen: Conjunto de valores dependientes (eje Y).
