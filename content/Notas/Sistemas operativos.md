# Sistemas operativos
- También abreviados como **SOs**: Conjunto de programas que coordinan y dirigen los recursos utilizados por la máquina. Sirve a modo de intermediario entre software y hardware, y se ejecuta de manera privilegiada.
- La parte más importante es el **kernel**, el cual se encarga de gestionar el uso del hardware por los programas.
- Un sistema operativo eficiente sabe priorizar la ejecución de ciertos programas o reservar el uso de tanta cantidad de software dependiendo de para qué se lo necesite. 
	- También debe ser capaz de poder manejar errores con eficacia.
- Los más populares son [[Windows 1]], [[Linux]], [[MacOS 1]], Android, etc.
## Funciones principales
- Coordinar, planificar y sincronizar procesos, y permitir la comunicación entre ellos.

> [!TIP] Qué es un proceso
> Una aplicación que necesita una serie de recursos para realizar su tarea, ya sea tiempo de CPU, memoria, archivos o periféricos.

- Administrar la memoria RAM.
	- Asignar espacio a ciertos procesos o archivos.
	- Liberar memoria cuando sea necesario.
	- Conocer qué parte de la memoria es usada y por quién.
- Administrar ficheros.
- Gestionar periféricos y hardware conectado.
- Lanzar programas a petición del usuario.
- Facilitar llamadas al SO mediante APIs.
- Gestionar el acceso de los usuarios al software.
## Tipos de SOs
- Dependiendo de la cantidad de usuarios: **monousuario** y **multiusuario**.
- Dependiendo de las tareas: **Multitarea** o **Monotarea**.
- Dependiendo del uso de recursos: 
	- **Centralizado**: Controla un solo ordenador.
	- **Distribuido**: Controla varios al mismo tiempo.
