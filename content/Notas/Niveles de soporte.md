# Los 5 niveles de soporte de IT
- Fundamental para resolver los problemas de los usuarios, pero se debe tener niveles que permitan filtrar por dificultad cada problema.
- Nivel 0 - Autoservicio.
	- Herramientas para el cliente que podrían solucionar el problema.
		- Portales de autoservicio, FAQs.
	- Suelen ser soluciones a problemas sencillos o generales.
- Nivel 1 - Soporte básico de primera línea.
	- Primer contacto directo con empleados.
	- Se debe saber cuándo delegar el problema a niveles superiores.
- Nivel 2 - Soporte avanzado.
	- El personal puede resolver problemas complejos y de back-end.
	- Conocen hardware y software de la empresa.
- Nivel 3 - Experto en la materia.
	- El empleado conoce a profundidad un sector de la infraestructura.
	- Tiene información muy avanzada.
	- Pueden alterar el software involucrado.
- Nivel 4 - Soporte externo.
	- Soporte proporcionado pero no respaldado por la empresa.
	- Por ejemplo, soporte para periféricos proporcionado por tercero, como impresoras.
