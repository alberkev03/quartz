# Distribuciones Linux
- Conjunto formado por el sistema operativo [[Linux|GNU/Linux]] base y un conjunto de aplicaciones, todo ya compilado y listo para usar.
- Existen multitud de distribuciones, orientadas a múltiples usos. 
	- De sobremesa: Pensados para ordenadores personales, fáciles de usar.
	- De servidores: Pensados para servidores y uso empresarial. Proporciona herramientas para tal fin, como alojamiento web, gestión de databases y redes.
	- Especializadas: Diseñadas para suplir necesidades concretas de negocios, instituciones o usuarios. Suelen ser de nicho.
- Dependiendo de los requisitos del usuario, existen distribuciones con binarios ya compilados y otras las cuales hay que compilar en el momento de instalar cualquier software, como Gentoo.
