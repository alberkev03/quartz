# Sistemas
- Conjunto de elementos relacionados con un objetivo común.
	- Los elementos son conceptos, cosas físicas y personas.
- Componentes básicos:
	- Un objetivo en común.
	- Relaciones estables entre objetos del sistema.
	- Fronteras entre fronteras.
		- Lo que está fuera de las fronteras es incontrolables.
	- Elementos identificables y subsistemas.
	- Procesos que convierten entradas y salidas.
		- Entrada: recursos desde el ambiente.
		- Salida: igualmente de recursos.
	- [[Organización 1]] para lograr el objetivo.
