# Unidades de memoria
- La computadora utiliza código binario. Cada unidad es llamada un bit, y es la *unidad mínima de información*. Los bits se separan en cantidades fijas dentro de la memoria.
	- **8bits**
	- **16bits**
	- **32bits**
	- **64bits**
- Cada uno de estos grupos tiene su dirección dentro de la memoria.
- Estos bloques sirven para representar datos mediante [[Codificación]].
