# Antivirus
Programa de software diseñado para prevenir, detectar y eliminar virus informáticos u otros tipos de [[Malware]]. 
## Funcionamiento básico del antivirus
El objetivo es proteger la computadora del usuario de cualquier malware potencialmente peligroso. 
- Escaneo de archivos. Si se encuentra un archivo sospechoso, se compara con una base de datos conocida, y de coincidir se elimina.
- Protección en tiempo real. Los antivirus monitorean constantemente el sistema y detienen cualquier amenaza detectada.
- Actualización de la base de datos. La misma se mantiene al día con las amenazas conocidas. 
- Análisis heurístico. Además de comparar con malware conocido, el antivirus busca activamente patrones de conducta sospechosos o maliciosos.
- Eliminación del malware. Si el antivirus detecta un archivo, lo elimina o pone “en cuarentena”. 
	- El archivo no se ejecuta hasta que se decida qué hacer con él.
## Funcionamiento adicional del antivirus
Algunos antivirus cuentan con funcionalidades adicionales.
- Escaneo de archivos.
- Actualizaciones automáticas de base de datos de virus y definiciones de posibles ataques.
- Análisis de comportamiento sospechoso.
- Protección contra phishing, es decir, sitios web maliciosos que intentan robar información personal.
- Análisis programado.
- Protección de correo electrónico.
- Protección en múltiples [[Sistemas operativos]].
## Tipos de antivirus
Según su enfoque y visión, se los clasifica de la siguiente manera.
- Basado en firmas, es decir, bases de datos conocidas, comprobando el archivo y buscando patrones que coincidan.
- De comportamiento, buscando procesos sospechosos o maliciosos, como la modificación de archivos críticos o acceso a datos privados.
- Seguridad de red, ante amenazas externas que puedan entrar mediante internet, correo electrónico, etc.
- Seguridad de servidor, que protege ante ataques externos e internos.
- De móviles, diseñado para teléfonos y tabletas.
## Desventajas
Los antivirus son muy recomendados para el usuario común. Sin embargo, presenta algunas desventajas importantes.
- Falsos positivos.
- Coste.
- No es 100% eficaz.
