# Microprocesador
- “Cerebro” de una computadora.
	- Ejecuta programas mediante operaciones lógicas y aritméticas.
## Arquitectura del procesador
- Impacto directo en la cantidad de [[Circuitos Lógicos]].
	- RISC (Reduced Instruction Set Computing): Conjunto simple de instrucciones.
		- Menos [[Transistores]], pero más ciclos de reloj.
	- CISC (Complex Instruction Set Computing): Instrucciones complejas.
		- Más [[Circuitos Lógicos]] para compensar.
## Núcleos
- Circuitos adicionales.
	- Gestionar instrucciones, cálculos, datos, tareas.
## Frecuencia de reloj
- Alta frecuencia = más [[Circuitos Lógicos]].
	- Más operaciones por segundo.
## Litografía
- Proceso de fabricación.
	- [[Transistores]] más pequeños.
		- Más [[Circuitos Lógicos]] por área.
## Tareas específicas
- Cálculos orientados a tareas específicas.
	- GPU, AI, Simulaciones, etc.
